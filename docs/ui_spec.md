# Gematria CipherLab — 画面仕様書

## 1. 画面構成

```text
┌──────────────────────────────────────┐
│ タイトル・説明・EN/JA切替            │
├──────────────────────────────────────┤
│ 基礎｜英語・ラテン文字｜Agrippa｜Hebrew │
├──────────────────────────────────────┤
│ タブ内容・方式選択・説明              │
├──────────────────────────────────────┤
│ 入力・プリセット・文字盤・計算・JSON読込│
├──────────────────────────────────────┤
│ 確認事項・3段階トレース・行内訳・比較   │
├──────────────────────────────────────┤
│ コピー・JSON保存・共有URL              │
├──────────────────────────────────────┤
│ 参照表・置換規則                      │
├──────────────────────────────────────┤
│ GitHubリンク                          │
└──────────────────────────────────────┘
```

## 2. 言語切替

- 表示は`?lang=ja|en`、保存値、ブラウザー言語の順で決める。
- 日本語ブラウザーは日本語、それ以外は英語を初期値とする。
- 切替時に`<html lang>`、本文、プレースホルダー、ARIAラベル、動的結果、フッターを更新する。
- 選択言語を`localStorage`の`gematria-lang`へ保存する。利用できない環境では保存せず継続する。
- 表示済みの結果は再描画だけを行い、入力から再計算しない。

## 3. タブ

| タブ | 内容 |
|---|---|
| 基礎 | 定義、背景、使い方、方式概要、限界、出典 |
| 英語・ラテン文字 | A=0、A=1、English ×6、Latin 23 |
| Agrippa | Agrippa 23、Agrippa 27枠 |
| ヘブライ文字 | Hebrew Standard、Hebrew Final Values、オンスクリーンキーボード |

タブは`role="tablist"`、`role="tab"`、`role="tabpanel"`と相互参照するIDを持ちます。選択中のタブだけを`tabindex="0"`とし、左右矢印、Home、Endで移動・選択できます。

## 4. 方式選択

英語・ラテン文字、Agrippa、ヘブライ文字ではセレクトボックスを使います。ヘブライ文字では、語末形を通常値で数えるStandardと、語末形だけを500〜900で数えるFinal Valuesを選べます。ⓘボタンは選択中方式の説明を`<dialog>`で開きます。説明は構造化した文とリストをDOM APIで生成し、HTML文字列を挿入しません。閉じると起点ボタンへフォーカスを戻します。

## 5. 入力

- 3行以上のテキストエリア、最大10,000文字
- 方式別プリセット
- ヘブライ文字タブで表示する文字盤。語末形5文字の表示値は選択方式に合わせて変える
- Enterで改行、Ctrl／⌘＋Enterで計算
- クリアと1文字削除は入力欄へフォーカスを戻す
- 1MB以下の`gematria-cipherlab.analysis` JSONを選び、再計算検証して復元する

プリセット選択と文字盤入力は自動計算しません。利用者が「計算」を選んだ時点の入力だけを結果に反映します。

## 6. 結果

### Step 1: Tokenization

入力順にチップを並べ、計算対象、置換、除外、無視を色と凡例で区別します。空白は`␠`で表示します。RTL方式ではトークン列を右から左へ表示します。

### Step 2: Value assignment

計算対象トークンだけをカードとして並べ、トークン、下向き矢印、数値を示します。置換したトークンは`W→HV`のように元と変換後を表示します。

### Step 3: Total

数値を`+`で結んだ式と合計を表示します。対象がない場合は0とします。除外文字は合計と分けて表示します。

正規化・置換と、空白・記号・母音記号などの無視は、トークン列の下にも要約します。方式にない文字がある場合だけ「確認事項」を表示します。

### 行・空白区切りの内訳

- 入力を物理行で分け、各行の合計、計算対象数、除外数を求める。
- 行内をUnicode空白の連続で区切り、各セグメントの文字列、合計、計算対象数、除外数を表示する。
- 空行も行番号を保持し、区切り単位なしと表示する。
- これは言語学的な単語分割ではなく、表示と検算のための空白区切りである。
- タブ、CR、LFは区切りとして無視し、方式未定義文字の警告にしない。

### 方式横断比較

- 選択方式と同じ文字体系の方式だけを比較する。
- 英語・ラテン文字では6方式、ヘブライ文字では2方式を同じ入力で計算する。
- 方式名、方式ID、方式版、合計、選択方式との差、計算対象数、除外数をカードで表示する。
- 選択方式を「基準」と表示し、合計の一致や近さを意味・信頼度として採点しない。
- 言語切替では保存済みの結果と比較を再描画し、再計算しない。

### コピー、JSON、共有URL

- 「結果をコピー」は、方式名、方式ID、方式版、入力、正規化後入力、計算トレース、合計、行内訳、方式比較、限界の注記を現在の表示言語で作る。
- Clipboard APIが使えない`file://`などでは、一時テキストエリアを使うフォールバックを試す。失敗時は`aria-live`の状態欄に通知する。
- 「JSONを保存」は、選択方式の完全な分析結果と同一文字体系の比較要約を`gematria-cipherlab.analysis`形式で保存する。
- JSONの`formatVersion`は1、方式版は2.0.0とする。再現性のため生成時刻を含めない。
- 「JSONを読み込む」は1MB以下に限定し、形式名と版を確認する。入力・方式・比較方式から分析パッケージ全体を再計算し、保存内容と構造的に完全一致した場合だけ入力、方式、結果を復元する。
- 共有URLは`lang`と`scheme`だけを既定で含む。利用者がチェックした場合だけ`input`を追加し、URLが4,000文字を超える場合はコピーしない。
- 共有URLの入力はアクセス先で再計算する。合計やトレースをURLパラメーターとして受け取らない。
- 入力を含むURLがブラウザー履歴や共有先に残り得ることを、チェック欄の近くで明示する。

## 7. 参照表

- 選択方式の全トークンと数値を表示する。
- 計算に使われた行を強調する。
- 置換、除外、HI/HVの境界規則を表の下へ表示する。
- Agrippa 27枠はJ=600、V=700、HI=800、HV=900を含む27行とする。
- Hebrew Final Valuesは通常形を1〜400、語末形ך・ם・ן・ף・ץを500〜900で表示する。

## 8. レスポンシブ

### モバイル（320〜599px）

- 単一カラムを基本とする。
- 言語切替をタイトル下へ置き、重なりを防ぐ。
- タブを2列×2行にする。
- 計算ボタンを全幅にする。
- 行内訳、比較カード、コピー／JSON／共有操作を1列にする。
- 主要ボタンとタブは高さ44px以上にする。

### タブレット（600〜899px）

- 言語切替をヘッダー右へ置く。
- タブを4列1行にする。
- 方式カードを3列にする。
- 行内訳のセグメントと比較カードを複数列にし、コピー／JSONボタンを横並びにできる。

### デスクトップ（900px以上）

- 入力欄と計算／JSON読込操作を横並びにする。
- 本文の最大幅を960pxに保つ。
- 比較カードを3列にする。

全幅で横スクロールとタイトル・言語切替の重なりを発生させません。長い加算式だけは、その領域内で横スクロールできます。

## 9. アクセシビリティ

- すべての操作をキーボードで実行できる。
- `:focus-visible`へ3pxのアウトラインを表示する。
- 言語切替とⓘボタンのARIAラベルも翻訳する。
- 非表示パネルには`hidden`を使う。
- 色だけに依存せず、チップの文字、置換記号、凡例、警告文を併用する。

## 10. 初期状態とエラー

- 初期表示は基礎タブで、入力・結果・参照表を隠す。
- タブまたは方式を変えたら、以前の結果を消す。
- 入力が空でも0のトレースを表示する。
- 10,000文字を超えた入力は計算せず、確認事項を表示する。
- 入力変更、プリセット、文字盤、クリア、1文字削除では、入力と一致しなくなった古い結果を消す。
- JSON読込は構文不正、形式違い、未対応版、欠落、完全一致失敗、1MB超過を区別して通知する。失敗時は現在の入力と結果を変更しない。
- コピー、JSON保存、JSON読込、共有URLの状態は`role="status"`と`aria-live="polite"`で通知する。
- 有効な`scheme`を持つ共有URLは該当タブと方式を復元する。`input`がある場合だけ入力を復元して計算する。不正な値は復元しない。
- JavaScriptが無効でも基礎説明は読める。
